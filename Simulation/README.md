# Simulation

This directory contains the Mujoco Gymnasium-based RL environment for training and running policies on the simulated robot arm.

## Directory Guide

### ```assets```

Contains MJCF and STL files for describing 3D world

### ```environments```

Contains Mujoco Gymnasium environment files for each task

### ```models```

Contains trained RL policies

## Usage

Run ```learn.py``` script to train policy and ```test.py``` to script to test in simulation
